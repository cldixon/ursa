# Get started

Two pages take you from nothing to a working query.

<div class="grid cards" markdown>

-   **[Install](../install.md)**

    ---

    Install `ursa-graph` from PyPI. The wheels include the compiled core, so you need no Rust toolchain. Optional extras add Polars, NetworkX, NumPy, and SciPy interop.

-   **[Quickstart](../quickstart.md)**

    ---

    One Python session on a bundled dataset. It loads a graph, computes metrics, filters, traverses, and gets the result out.
