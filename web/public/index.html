Ursa Shell

Graph analytics in SQL, running entirely in your browser. Ursa's engine is compiled to WebAssembly; it reads the sample graphs below as Parquet over HTTP and runs the algorithms on your machine. Nothing is sent to a server.

Ctrl / ⌘ + Enter to run
