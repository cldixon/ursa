## Try it without installing

[Ursa Shell](https://ursa-shell.cl-dixon.workers.dev) is the `ursa` shell in a web page. It runs the same engine, compiled to WebAssembly, in your browser: pick a dataset from its menu, or import a file of your own, which stays on your machine.

Looking for the Python library? Its documentation is at [cldixon.github.io/ursa](https://cldixon.github.io/ursa/).
